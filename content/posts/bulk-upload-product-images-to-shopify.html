A photographer sends you 600 images in a folder. Each product needs three to six of them, in the right order, with alt text. Dragging them into Shopify product by product takes a full day. If the files are named well, it can take a few minutes instead. This guide shows the naming that makes images match themselves.

Why Shopify's import makes images hard

Shopify's product CSV import doesn't take image files. It takes a web address for each image, in an "Image Src" column, and the image must already be online where Shopify can download it. So you first upload every file somewhere, collect 600 links, and paste each one into the right row. That's the slow part.

The faster way is to let the file name say which product an image belongs to.

Name each image after its product

Add an "Image Name" column to your product sheet and give each product a short, unique name. Then name the files after it, with a number for the order:

In Bulk Product Uploader, capitals, spaces, dashes and underscores don't matter, and a number at the end (with a space, dash, underscore or in brackets) sets the order. Folders don't matter either: Sofas/Oslo Sofa.jpg works the same as a file at the top.

Good naming habits

  • Use the same name in the sheet and on the files. If your photographer names files by SKU, use the SKU as the image name in the sheet. That's often the easiest.
  • Keep names unique. "Sofa" for two different sofas sends all their photos to both.
  • Put the main photo first. The file without a number, or with the lowest number, becomes the first image, which Shopify shows in collections.
  • Rename in bulk, not by hand. Windows File Explorer can rename a selection to "Oslo Sofa (1)", "Oslo Sofa (2)" and so on: select the files, press F2, type the name and Enter. On a Mac, select the files and choose Rename from the right-click menu.

Size and format

Shopify recommends square product images of 2048 × 2048 pixels for zoom. JPG is best for photos, PNG for images with transparent backgrounds, and WebP for smaller files. Keep each file well under 20 MB; most good product photos are under 1 MB.

Alt text without writing it 600 times

Alt text describes the image for screen readers and search engines. If you leave the alt text column empty, Bulk Product Uploader uses the product title, which is a sensible default. For better SEO, add an "Image alt text" column with a short description, such as "Oslo 3 seater sofa in grey linen".

Products that already have images

Decide this before you upload. You can add the new images and keep the old ones, skip products that already have images (useful to fill in only the gaps), or replace all images with the new set. An image that's already on the product isn't uploaded twice.

Check before you upload

Run "Check image matches" first. It lists the images each product will get, and the images that match no product at all. Those leftovers are almost always a typo in a file name, and they're much easier to fix now than after the upload.
